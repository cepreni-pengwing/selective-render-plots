# Selective Render Plots

Optional server add-on for [Selective Render](https://modrinth.com/mod/selective-render). Players can isolate their PlotSquared plot with `/sr plot`, with exact outlines including merged plots.

- **Paper:** 1.20.1 and 1.21.1, needs PlotSquared
- **Fabric:** 1.20.1, needs the ArdaCraft PlotSquared Fabric port
- Players need the Selective Render client
- Permission: `selectiverender.plot.solo`

Details: [GitHub](https://github.com/cepreni-pengwing/selective-render-plots#readme) · Contact: [pengwing.ac@gmail.com](mailto:pengwing.ac@gmail.com)
