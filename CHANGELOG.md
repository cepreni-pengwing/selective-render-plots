# Changelog

All notable changes to Selective Render Plots are documented here.

## 1.1.1

### Changed

- Project license changed from MIT to GPL-3.0-only.
- Documentation now covers Selective Render 1.7.4 plot margins and custom temporary Y bounds.

### Added

- Added an embedded icon to the Fabric server mod.
- Automated protocol tests, Java 17 common-module tests, and Java 21 platform builds.
- Contribution guidance and structured issue forms.
- Tag-driven builds for future GitHub releases.

## 1.1.0

### Added

- Native server bridge for the ArdaCraft PlotSquared Fabric port.
- Separate Paper and Fabric distribution JARs backed by one shared protocol module.

## 1.0.1

### Changed

- Project license changed to MIT.
